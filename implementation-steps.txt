Step 6 : deploy ingress controller to deliver our entire application to the outside world. 

6.1 : Use the shared iam_policy.json document and create an IAM policy in your AWS account. Name the policy as "AWSLoadBalancerControllerIAMPolicy"

aws iam create-policy --policy-name AWSLoadBalancerControllerIAMPolicy --policy-document file://iam_policy.json

arn:aws:iam::992189742322:policy/AWSLoadBalancerControllerIAMPolicy


6.2 : Create an Service account (IRSA - IAM Role for Service Account)

eksctl create iamserviceaccount --cluster=ekswithavinash --namespace=kube-system --name=aws-load-balancer-controller --attach-policy-arn=arn:aws:iam::992189742322:policy/AWSLoadBalancerControllerIAMPolicy --override-existing-serviceaccounts --region ap-south-1 --approve

kubectl get sa -n kube-system
kubectl describe sa aws-load-balancer-controller -n kube-system

6.3 : Add helm chart and install with IRSA we created at step 2

helm repo add eks http://aws.github.io/eks-charts
helm repo update eks


6.4 : Install the helm chart, Make sure to pass the IRSA while installing

helm install aws-load-balancer-controller eks/aws-load-balancer-controller -n kube-system --set clusterName=ekswithavinash --set serviceAccount.create=false --set serviceAccount.name=aws-load-balancer-controller

Step 7 : create an IAM role for a service account for the notification service that can assume the SES service to send alerts. 

7.1 the service account should be in the same namespace as the notification service. 

kubectl create ns task-management

7.2 Create service account

eksctl create iamserviceaccount --cluster=ekswithavinash --namespace=task-management --name=notification-service-sa --attach-policy-arn=arn:aws:iam::aws:policy/AmazonSESFullAccess --override-existing-serviceaccounts --region ap-south-1 --approve

kubectl describe sa notification-service-sa -n task-management

eks.amazonaws.com/role-arn: arn:aws:iam::992189742322:role/eksctl-ekswithavinash-addon-iamserviceaccount-Role1-EUO6Wa3jzliZ

7.3 our accounts will be in sandbox mode for SES as we are on the free plan so create some identities, at least two email IDs. We can use that as a sender and receiver in our task management application.
